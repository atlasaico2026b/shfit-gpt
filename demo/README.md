# دادهٔ نمونه برای تست (بخشی از برنامه نیست)

`atlas-shift-demo-10.json` یک **فایل پشتیبان ATLAS SHIFT** است که در هر بخش دقیقاً **۱۰ آیتم** دارد:

| بخش | تعداد | بخش | تعداد |
| --- | --- | --- | --- |
| کارکنان | ۱۰ | یادداشت‌ها و پیگیری‌ها | ۱۰ |
| مأموریت‌ها | ۱۰ | برنامه‌ها و پرونده‌های اقدام | ۱۰ |
| مرخصی‌ها | ۱۰ | اشکالات و رفع اشکال | ۱۰ |
| خودروها | ۱۰ | سوابق سرویس و تعمیر | ۱۰ |
| ایستگاه‌ها و مراکز | ۱۰ | سوابق گازسنج | ۱۰ |
| گازسنج‌ها | ۱۰ | برنامهٔ شیفت‌ها | ۱۰ |

به‌علاوه ۱۰ سطر سابقه (تاریخچه) تا صفحهٔ «سوابق» هر رکورد هم داده داشته باشد.
شناسه‌ها با پیشوند `demo-` شروع می‌شوند (`demo-emp-01`، `demo-lev-03`، …) تا در دادهٔ واقعی با چیزی قاطی نشوند،
و ارجاع‌ها (مرخصی → کارمند، مأموریت → کارمند/خودرو، سوابق گازسنج → گازسنج، سرویس → خودرو) همه به رکوردهای
همین فایل وصل‌اند. تاریخ‌ها نسبت به روز ساخت فایل (حدود آبان ۱۴۰۵) پخش شده‌اند تا داشبورد و تقویم هم پر باشد.

## این فایل در کد برنامه نیست

`index.html`، `modules.js`، `sw.js` و فرآیند ساخت پیش‌نمایش (`shogo.preview.json`) هیچ‌کدام به این پوشه ارجاع
ندارند؛ پس برنامه با همان حالت خام و بدون داده بالا می‌آید و این فایل فقط وقتی خودت بخواهی بارگذاری می‌شود.

## چطور بارگذاری کنم

۱. فایل `atlas-shift-demo-10.json` را دانلود کن.
۲. در برنامه: **تنظیمات → پشتیبان‌گیری و ذخیره‌سازی → بازیابی نسخهٔ پشتیبان → انتخاب فایل پشتیبان** و همان فایل را
   انتخاب کن و تأیید کن.
۳. صفحه بازخوانی می‌شود و هر بخش ۱۰ آیتم دارد. داشبورد، تقویم، زنگ اعلان‌ها و همهٔ خروجی‌ها (CSV/Excel/Word/PPT/PNG
   و چاپ/PDF در A4 افقی) با همین داده قابل آزمایش‌اند.

> ⚠️ بازیابی، اطلاعات فعلی همان دستگاه را **جایگزین** می‌کند. اگر دادهٔ واقعی روی آن دستگاه داری، اول از
> «دریافت فایل پشتیبان» یک نسخه بگیر.

## چطور دادهٔ تست را پاک کنم

راه ساده: از همان صفحه یک نسخهٔ پشتیبان از دادهٔ واقعی خودت بگیر و بازیابی کن؛ یا برای شروع تمیز، یک فایل
پشتیبان با آرایه‌های خالی بساز:

```json
{ "app": "ATLAS SHIFT", "schemaVersion": 2, "data": {
  "schemaVersion": 2, "settings": {}, "references": {}, "history": [], "shifts": [],
  "employees": [], "missions": [], "leaves": [], "vehicles": [], "stations": [],
  "gasmeters": [], "notes": [], "programs": [], "faults": [], "maintenance": [], "gaslogs": []
} }
```

## بررسی خودکار

```bash
node tests/demo-data.cjs
```

ساختار فایل، یکتایی شناسه‌ها، ده‌تایی‌بودن هر بخش، درستی ارجاع‌ها، قالب تاریخ‌ها و بیرون‌بودن این پوشه از کد
برنامه را می‌سنجد.
