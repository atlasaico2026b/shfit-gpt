# ATLAS SHIFT

رابط فارسی و راست‌چین برای ساخت سامانه محلی مدیریت نیروی انسانی، شیفت‌ها و مأموریت‌ها.

## وضعیت فعلی

این commit ساختار رابط را یکپارچه می‌کند؛ **هنوز نسخه عملیاتی برای ثبت و مدیریت داده‌های واقعی نیست**. داشبورد دارای پنجره‌های نمایشی، زنگوله اعلان، تقویم شمسی، میان‌برهای ۹ پنجره، تغییر تم و چیدمان قابل‌کشیدن است. تنظیمات ظاهر و ترتیب پنجره‌ها در همین مرورگر ذخیره می‌شوند.

صفحه‌های کارکنان، مأموریت‌ها، مرخصی‌ها، خودروها، گازسنج‌ها، یادداشت‌ها و گزارش‌ها اکنون در همان پوسته نمایش داده می‌شوند؛ فرم‌ها، مدل داده و ذخیره‌سازی واقعی هر ماژول باید در مراحل بعدی تکمیل شود. تا آن زمان، صفحه‌ها عمداً به رابط قدیمی یا فایل دیگری هدایت نمی‌شوند.

## ساختار اصلی

- `index.html`: تنها نقطه ورود برنامه و مرجع رابط
- `styles.css`: تم و ظاهر مشترک؛ جایگزین فایل CSS رابط قبلی شده است
- `app.js`: تعاملات داشبورد، ناوبری داخلی و انتخاب بازه زمانی
- `manifest.json` و `sw.js`: زیرساخت نصب‌پذیری وب و کش منابع ثابت
- `dashboard.html`: نشانی سازگاری قدیمی؛ فقط به `index.html` هدایت می‌کند و نسخه دوم رابط نیست

## اجرا و آفلاین

- برای توسعه محلی، فایل‌ها را در یک پوشه نگه دارید و `index.html` را باز کنید؛ مسیرهای منو به فایل‌های دیگرِ دارای تم قدیمی وابسته نیستند.
- Service Worker فقط از محیط امن مانند HTTPS یا localhost ثبت می‌شود؛ در اجرای مستقیم `file://` فعال نمی‌شود.
- نسخه وب پس از بارگذاری اولیه از طریق HTTPS می‌تواند منابع کش‌شده را آفلاین باز کند.
- این هنوز بسته بومی قابل انتشار نیست. برای نصب مستقل روی Android و Windows و سپس سایر سیستم‌ها باید بسته‌بندی، ذخیره‌سازی محلی پایدار، مهاجرت داده، پشتیبان‌گیری/بازیابی و آزمون آفلاین اضافه و بررسی شود.

## تصمیم معماری

ظاهر فقط یک بار، در رابط اصلی نگهداری می‌شود؛ بازطراحی بعدی باید همین فایل‌ها را **جایگزین یا اصلاح** کند، نه اینکه نسخه موازی از داشبورد بسازد. داده‌های واقعی هر ماژول نیز باید در لایه ذخیره‌سازی مشترک تعریف شوند؛ فایل‌های رابط نباید به مسیرهای مطلق ویندوز یا URLهای اینترنتی برای قابلیت‌های اصلی وابسته باشند.
