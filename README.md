# ATLAS SHIFT

سامانه محلی مدیریت پرسنل، شیفت‌ها و مأموریت‌ها؛ رابط فارسی و راست‌چین با تقویم هجری شمسی.

## قابلیت‌های نسخه 0.1.0

- پرونده پرسنلی: نام، کد پرسنلی، واحد، سمت و الگوی کاری پایه
- برنامه‌ریزی روزانه و چندروزه: شیفت ۱۲ ساعته، روزکار، مأموریت شهری و بین‌شهری، انتقال و انواع فعالیت سفارشی
- ثبت شهر/مکان، مبدأ، مقصد، کیلومتر مسیر، ساعت شروع/پایان و یادداشت
- تقویم شمسی ماهانه و فهرست برنامه‌های هر روز
- مدیریت واحدها و انواع فعالیت از داخل تنظیمات
- ذخیره‌سازی در localStorage؛ بدون حساب کاربری، سرویس ابری یا ارسال اطلاعات به سرور
- دریافت و بازیابی فایل پشتیبان JSON
- فایل‌های قابل کش شدن برای استفاده آفلاین پس از اولین بارگذاری

## اجرا

برای پیش‌نمایش سریع می‌توان index.html را در مرورگر باز کرد. برای نصب‌پذیری و استفاده آفلاین کامل، برنامه را روی یک دامنه HTTPS یا یک سرور محلی اجرا کنید؛ Service Worker در حالت file:// فعال نمی‌شود.

برای انتشار ساده، مخزن را در GitHub Pages از شاخه main و مسیر root منتشر کنید. فایل‌های مورد نیاز در ریشه مخزن قرار دارند.

## نکته مهم درباره ذخیره‌سازی

داده‌ها به مرورگر و دستگاه فعلی وابسته‌اند. پاک کردن داده‌های مرورگر یا استفاده از دستگاه/مرورگر دیگر ممکن است به از دست رفتن اطلاعات منجر شود. پشتیبان JSON را منظم دریافت و در محل امن نگهداری کنید. این نسخه همگام‌سازی چندکاربره ندارد و برای استفاده سازمانی هم‌زمان هنوز نیازمند طراحی و آزمون تکمیلی است.

## کنترل دستی نسخه اولیه

1. یک پرسنل بسازید و سپس یک شیفت با تاریخ امروز ثبت کنید.
2. تقویم شمسی را باز کنید و نمایش برنامه در روز مربوطه را بررسی کنید.
3. یک مأموریت بین‌شهری با مبدأ، مقصد و کیلومتر ثبت کنید.
4. نام یک واحد یا نوع فعالیت را در تنظیمات ویرایش کنید.
5. فایل پشتیبان دریافت کنید و بازیابی آن را با احتیاط آزمایش کنید.
